# RSRFuse: Reliability-aware Subband Routing for Nighttime Infrared and Visible Image Fusion

This repository is the project page for **RSRFuse**, a lightweight infrared and visible image fusion network designed to improve robustness in nighttime scenes.

## Overview

RSRFuse addresses the confusion between informative textures and sensor noise in low-light visible images.

The framework integrates three main components:

- **Reliability-aware subband routing:** Adaptive modality weighting using local luminance and wavelet-domain noise-related cues.
- **Scale-aligned wavelet fusion:** Efficient multi-scale feature integration using lightweight subband blocks.
- **Noise-aware training:** Improved robustness to visible-image noise while preserving useful source information.

## Experimental Evaluation

The method is evaluated on five datasets: MSRS, LLVIP, MRLL, TNO, and RoadScene.

## Code Availability

The source code, pretrained models, and evaluation scripts are not publicly available yet.
